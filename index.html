RadFeedback

Demo · Not for clinical use

Formative feedback from the edits attendings already make.

Every preliminary report a resident writes is finalized by an attending. RadFeedback reads those edits, sorts them by how much they matter, and turns a rotation's worth into weekly feedback the resident can act on.

Try the demo

The demo opens with a finished analysis of a synthetic rotation: five residents, 120 report pairs, fictional names. Nothing is sent anywhere; it runs entirely in your browser.

Open the demo

Best on a laptop. It opens on Resident View: tap a resident ID to see their weekly feedback, choose Program Dashboard for the rotation overview, or Assess Feedback for the pairs set aside for a radiologist's review, each with the reason it is there.

How it works

  1. Pair. The program exports its preliminary and final reports. Identical pairs and trivial edits are set aside before anything is sent for grading.
  2. Grade. Each remaining edit is classified on a four-tier scale, with the model allowed to decline when an edit is ambiguous. Pairs it cannot compare, or declines, are listed for a radiologist rather than counted.
  3. Report. Counts are aggregated in code; a short narrative per resident and per week cites the actual edited sentences, so every point can be checked against the source.
